# External Research References

## Vodka

https://github.com/Shellworks-Development/vodka

Vodka is used only as an external architecture and implementation reference for research into areas such as

- FEX-Emu
- ARM64 Linux runtime environments
- Wine x86_64
- rootfs design
- runtime separation
- DXVK / Vulkan planning
- Android integration

Do not blindly copy code

Study each subsystem independently and only adapt ideas or code that are technically appropriate for StudioDroid v2

Verify licenses and attribution requirements before integrating any external source code

## Excluded projects

baldbuffalo/Roblox-Studio-on-Android must not be used as a source or reference

The previous RobloxDroid / StudioDroid implementation is intentionally not treated as a reference because StudioDroid v2 is a fresh second-generation architecture
